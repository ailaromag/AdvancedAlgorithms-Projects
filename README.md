# Advanced Algorithms - Projects

Lab projects developed for the **Advanced Algorithms** course (BSc in Computer Engineering, UIB, 2025/2026).

The projects in this index were developed by **Aila Romaguera and Carlos Garrido**, except for Project 1 (individual, Aila Romaguera). The group achieved the top score of the course across the full set of labs.

| # | Project | Description | Repo |
|---|-----|-------------|------|
| 1 | MVC Pattern & Asymptotic Cost Analysis| Event-based Swing/MVC app that plots real vs. theoretical costs of O(n), O(n·log n), O(n²) and O(n³) algorithms in real time. | [GitHub](https://github.com/ailaromag/Practica1-MyAlgorismesAvancats) |
| 2 | Backtracking: Hamiltonian Tour Variant | Backtracking solver for a multi-piece Hamiltonian chessboard tour. | [GitHub](https://github.com/ailaromag/Practica2-AlgorismesAvancats/blob/aila/model/README.md) |
| 3 | Divide & Conquer: Distances in a Point Cloud | Closest and farthest pair in a 2D point cloud, comparing five strategies (brute force, divide & conquer, convex hull, spatial grid, K-D tree) with a real-time benchmark. | [GitHub](https://github.com/ailaromag/Practica3-AlgorismesAvancats) |
| 4 | Huffman Coding: Lossless Compressor | Lossless Huffman compressor/decompressor comparing three priority-queue structures (binary heap, Fibonacci heap, ordered list), with live entropy/ratio metrics and benchmarking. | [GitHub](https://github.com/ailaromag/Practica4-AlgorismesAvancats) |
| 5 | Dynamic Programming: Game of 31 | Dynamic-programming solver for the Game of 31 with three approaches (top-down memoisation, bottom-up tabulation, sliding window), showing the shift from exponential to polynomial cost. | [GitHub](https://github.com/CarlosGarridot/Practica5-AlgorismesAvancats) |
| 6 | Modified Connect Four: Branch & Bound Agent | Branch & Bound (minimax + alpha-beta) agent for a modified 7×7 Connect Four (piece removal + 90° rotation), with move ordering, Zobrist transposition table and root parallelism. | [GitHub](https://github.com/ailaromag/Practica6-AlgorismesAvancats) |
| 7 | Monte Carlo: Game of the Goose | Monte Carlo simulator estimating the turn-count distribution of the Game of the Goose over N games, with statistical indicators, board heatmaps, convergence curves and a parallel execution mode. | [GitHub](https://github.com/CarlosGarridot/Practica7-AlgorismesAvancats) |
